
# Employee Learning and Skill Certification Tracker

A serverless Learning Management System (LMS) built using AWS and DevOps tools.

## Project Overview

An internal LMS where HR administrators can create courses, assign them to employees, track learning progress, and automatically issue certificates after successful quiz completion.

## Features

- HR course creation with YouTube/Vimeo videos
- Role-based and individual course assignments
- Email notifications using Amazon SES
- Multiple-choice quizzes with SHA-256 hashed answers
- Maximum of 3 quiz attempts per employee
- Automatic quiz grading using AWS Lambda
- PDF certificate generation and S3 storage
- Public certificate verification API
- HR skill-gap dashboard
- Department-wise skill completion matrix
- Weekly overdue notifications using SNS
